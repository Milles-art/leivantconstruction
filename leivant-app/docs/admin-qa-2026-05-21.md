## Role Permissions

- `super_admin`: full admin access.
- `manager`: dashboard, client pipeline, projects, catalog, providers, reviews, and order viewing.
- `sales`: dashboard, client pipeline, projects, and reviews.
- `content`: dashboard, catalog, providers, and reviews.
- `provider`: no admin command-center access.

Navigation now hides admin modules the signed-in role cannot use, and route middleware blocks direct URL access.

## Responsive Layout Notes

- Admin shell uses responsive grid/sidebar behavior for desktop, tablet, and mobile.
- Filter bars and tables use responsive wrapping/overflow to avoid broken columns on smaller screens.
- Critical admin actions remain visible as stacked controls on narrow widths.
